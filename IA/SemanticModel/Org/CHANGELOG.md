## [2026-05-08] - Fundamentación Arquitectónica e IA

### Added
- **`research_about_semantic.md`**: Creado como documento raíz abordando la diferencia entre intención e implementación, e incluyendo la primera versión conceptual del JSON multidimensional.
- **`semantic_research_analysis.md`**: Creado para ordenar el debate estructural, analizando los pros y contras del Modelo Canónico estricto frente a las Ontologías (grafos de conocimiento) e introduciendo las representaciones matriciales (Entity-Feature, Adyacencia, Co-ocurrencia).
- **`semantic_model_philosophy.md`**: Creado para asentar dos axiomas fundamentales: El arquitectónico (Representar vs. Reproducir) y el matemático (Estadística Bayesiana y probabilidad de inferencia).
- **`pipeline_agente_extractor.md`**: Creado para detallar el flujo de un Agente Autónomo capaz de extraer modelos semánticos resolviendo el problema de costes (*token limits*) y la heterogeneidad de lenguajes (R, C++, etc.).
- **`ROADMAP.md`**: Añadido para trazar las fases futuras del aprendizaje, desde la teoría hacia las pruebas de concepto.
- **`CHANGELOG.md`**: Añadido para la trazabilidad de los conocimientos adquiridos.

### Changed
- Actualización en `research_about_semantic.md` para incluir el cierre sobre ontologías y grafos como evolución necesaria frente al JSON plano.
